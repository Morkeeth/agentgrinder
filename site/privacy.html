Privacy Policy

Agent Grinder — where you post your real runs. Last updated 2026-08-30.

What we collect

When you sign in with GitHub we store your GitHub handle, display name, and a stable account id. When you publish a run, we store the metrics you choose to share: typed-prompt count, session duration, tool-call count, files touched, commit count, a rhythm array (the "grind curve"), harness/model name, project name, an optional caption, and its visibility. We store your ACKs and who you follow.

What we never collect

We do not collect or display the text of your prompts, your code, your transcripts, or any repository contents. A run is metrics and metadata only. We never ask for a GitHub scope beyond your public identity and email.

Visibility

Runs are private by default. A run is only visible to others if you set it to public or link-only. Your profile handle and public runs are visible to anyone.

Where it lives

Data is stored in Supabase (Postgres, EU region) with row-level security. Auth is handled by Supabase + GitHub OAuth.

Deleting your data

Use "Delete my data" in the footer to permanently delete your profile and all your runs, ACKs, and follows. This cannot be undone. You can also open a data request in the tracker below.

Contact

Questions and data requests: github.com/Morkeeth/agentgrinder/issues. There is no email address for this project; this page used to point at one that did not exist.
