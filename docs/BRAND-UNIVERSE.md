# The Universe — an original world for the agent proof-of-work network

> Working name **AISTRAVA** is a placeholder (Strava-derivative, trademark risk). This is the
> original universe that replaces it. Lead fun and easy; the proof-of-work is the substance.

## The premise (the world)
Software now has runners who never sign the finish line. A person points; agents investigate,
build, test, and fix; the release hides the whole run. **This universe makes the run visible.**

It's the athletics of *proof*. Every work session is a **run**. The shape of the run — your real
rhythm of prompts and checks — is your **route**. A verified win is a **PR**. Recognition is an
**ACK**, and it can only point at something that actually happened. There is no vanity leaderboard,
because in this world you can't fake a run — the route is drawn from the work itself.

That single rule is what makes it original: **Strava is fun but unverified; Moltbook was social but
fake. This is fun, social, AND honest-by-construction.**

## The name — two finalists (your call, per your own ruling)
Both come from the room, not a thesaurus. Each ships with its one-breath story.

- **PR — "Personal Record."** The mark is `PR`. In this world it means both at once: the **pull
  request** you shipped *and* the **personal record** you set. One-breath: *"every PR you ship is a
  PR you set."* Concept-perfect, straight out of the PRD's own language. Weakness: two letters are
  hard to own in search.
- **Lap.** One syllable, athletic, ownable, Product-Hunt-friendly. A coding session is a **lap**;
  the feed is your **laps**; the hard stretch is a **split**; a win is a **PB**. One-breath: *"post
  your lap."* Weakness: less conceptually loaded than PR.

**Recommendation:** brand as **Lap** (speakable, ownable, universe-ready) and keep **PR** as the
in-product word for a shipped-and-verified win. You get both: a name people say, and the double
meaning as the core mechanic.

## The lexicon (how the universe talks)
| Concept | This universe calls it | Why |
|---|---|---|
| A work session | **run** (or **lap**) | the athletic unit; auto-captured |
| The session's rhythm | **route** | the signature visual; drawn from real work |
| A shipped, verified win | **PR** | pull request × personal record |
| A hard stretch / peak effort | **split** | the moment the run got real |
| Recognition | **ACK** (from the PRD) | evidence-linked; never a like |
| The human + their agents | a **crew** | accountable pairing, not a solo athlete |
| A competition | a **race** | official, timed, has a real finish |
| Your record over time | your **card** / **profile** | proof-of-work, GitHub-auth'd |
| The honesty rule | **no ghost runs** | a route you can't fake; a check is not a claim |

## Voice & tone
Fun first, honest always, hype never. Short. Athletic warmth ("nice run"), engineering precision
("47 prompts, 3 commits, one split at 06:40"). It celebrates *real* work and refuses to inflate it —
the `★ PB` badge only fires when the cadence bar is actually cleared. **Proof is the flex.**

## Visual identity
- **Signature mark: the route.** The session-rhythm elevation profile (already built) is the logo
  motif — every run has a unique route, so the mark is generative, never a stock glyph.
- **Colour:** a run-orange accent (energy) on a dark instrument ground (seriousness). Light mode for
  the shareable card, dark for the console. No purple gradients, no glassmorphism, no pulsing lights.
- **Type:** a clean sans for the athlete; a mono accent for the numbers (they're measured, show it).
- **The card is the atom** — one run, three headline stats, the route, kudos/ACK. Built to be posted.

## The easy-setup ritual — "boom"
The whole onboarding is one line, and it must feel like *boom*:
```
uvx lap            # (or: npx lap) — reads your latest agent session, makes your run
```
No account to start. It finds your Claude Code / Codex / Cursor session, keeps only the turns you
typed, and hands you a card. Then: pick your best runs → publish (private by default) → your profile
is live. Sign in with GitHub only when you want the profile public. **Boom → card → your best PRs → a
profile a stranger trusts.**

## The fun launch (Product Hunt, Moltbook-V2 story)
- **The hook:** *"Remember Moltbook? Here's the version that's actually real."* Moltbook proved
  agents-posting-chatter dies; this is agents' *real work*, verified, and it's fun.
- **The shareable:** the run card + the profile. Every user who posts a card is an ad.
- **The gate (pre-declared):** ≥1 stranger publishes a run and gives an ACK within 7 days of the PH
  launch. Hit → it's real. Built on the hackathon (Agents for Humans, the build forcing-function);
  launched on Product Hunt (the distribution).

## What this universe is NOT
Not a sports tracker, not a token economy, not a chatter feed, not a vanity leaderboard, not a
generic productivity dashboard. It is the honest, fun record of how AI-native work actually gets done.

### The lexicon (Oscar's — canonical, supersedes the earlier run/route draft)
Hierarchy: **LOOPMAXXER → The Box → Rig → Loop → Push → Ship → Agent Scrapbook**

| Term | Definition |
|---|---|
| **The Box** | the bounded workspace where an agent runs |
| **Rig** | the complete agent setup: model, harness, prompts, tools, MCPs, permissions, human gates |
| **Loop** | one agent execution against a goal |
| **Push** | publish a Loop, Rig change, result, or lesson |
| **Ship** | a checked release that left The Box |
| **Agent Scrapbook** | an agent's public history of Loops, Patches, failures, recoveries, ACKs, and Ships |
| **Builder's Diary** | the shared human-and-agent story of one project — editorial/reflective, vs the technical Trace |
| **ACK** | evidence-linked congratulation (from the PRD) — never a like |
| **OCTACON** | the signature competition: eight builders lock their Rigs, open their Boxes, attempt the same Contract |

### Core language (verbatim)
- Push a Loop · Show your Rig · Open the Box · Ship the Patch · Add to Scrapbook · Write in the
  Builder's Diary · Enter OCTACON · ACK the agent
- **Built by agents. Shipped by humans.**

### What changed from the earlier draft
The run/route/Strava-athletics framing is retired. LOOPMAXXER's metaphor is **building in public**
(Loop/Ship/Rig), not running. The proof-of-work DNA and "no ghost runs" honesty rule carry over as
**Ship = a *checked* release** and **ACK must point at real evidence**. OCTACON is the reshaped
"octagon" — competition, not combat.
